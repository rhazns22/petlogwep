만든 이유

왜 만들었나요?

“영수증은 버려지지만,
기록은 남아야 하니까.”

반려동물이 아파 병원에 다녀오면, 영수증은 쉽게 버려지지만 기록은 오래 필요합니다.

PetLog는 복잡한 동물병원 영수증을 보호자가 이해하기 쉬운 지출 기록으로 정리하고, 병원 안내를 받은 복약·재진·회복 체크 내용을 함께 기록할 수 있도록 돕기 위해 만들었습니다.

⚠️

PetLog는 진단이나 처방을 제공하는 서비스가 아닙니다. 의료 판단을 대신하는 AI가 아니라, 보호자가 병원비와 지출 기록을 더 쉽게 이해하도록 돕는 기록 도구입니다.

Confirmed Data Pipeline

AI 초안과 사용자 확정 데이터를 분리한 신뢰성 설계

PetLog는 AI 분석 결과를 바로 저장하지 않습니다. Gemini가 생성한 영수증 분석 결과는 먼저 `draft` 상태의 AI 초안으로 표시되고, 보호자가 금액과 항목을 직접 확인·수정한 뒤 최종 데이터로 저장됩니다. 이 구조를 통해 AI 분석의 편의성은 유지하면서도, 실제 서비스 데이터의 신뢰도를 높였습니다.

Safety Guard

의료 판단 방지

AI는 진단이나 처방을 생성하지 않고, 지출 기록 초안과 참고용 브리핑만 제공하여 규제를 준수합니다.

Fallback 설계 분석 실패 시 사용자 경험이 끊기지 않도록 즉각적인 수기 입력 인터페이스로의 전환을 유도합니다.

Technical Deep Dive

Engine Logic Overview

AI 초안은 저장 전 검증 엔진을 거칩니다. 검증 엔진은 금액 정규화, 세금/할인 분리, 카테고리 보정, 의료성 표현 필터링을 수행한 뒤 사용자 확인이 필요한 `draft` 상태로 반환합니다.

validationEngine.ts (Public Pseudo-code) TypeScript 
function validateReceiptDraft(aiDraft) {
  // 1. 금액 정규화 및 총액 검증
  const normalizedAmount = normalizeAmount(aiDraft.amount);

  // 2. 세금 정보 교차 체크 (과세/면세/부가세 합계 확인)
  const taxChecked = validateTaxInfo({
    taxableAmount: aiDraft.taxableAmount,
    taxFreeAmount: aiDraft.taxFreeAmount,
    vat: aiDraft.vat,
    finalAmount: normalizedAmount,
  });

  // 3. 할인 금액 및 텍스트 분석 결과 검토
  const discountChecked = validateDiscountInfo({
    discountText: aiDraft.discountText,
    finalAmount: normalizedAmount,
  });

  // 4. 의료 판단/진단 관련 위험 키워드 필터링 (Safety Guard)
  const safeInsight = filterMedicalRiskTerms(aiDraft.insight);

  return {
    ...aiDraft,
    amount: normalizedAmount,
    taxInfo: taxChecked,
    discountInfo: discountChecked,
    insight: safeInsight,
    requiresUserConfirmation: true,
    status: "draft",
  };
}

“위 코드는 포트폴리오 설명을 위한 공개용 예시입니다. 실제 Gemini 프롬프트, API Key, Firebase Rules, 내부 검증 로직 전문은 포함하지 않았습니다.”
